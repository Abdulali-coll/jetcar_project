#CASE: JET-CAR WEBSTIE

Техническое задание для проекта JetCar
Цель проекта:
Создать удобный и минималистичный сайт для подбора и покупки автомобилей с user-friendly дизайном и адаптацией под мобильные устройства.

Основные страницы сайта:

Главная страница:
Эксклюзивное предложение автомобиля в верхней части страницы.
Кнопки фильтрации автомобилей по маркам (концепт).
Каталог доступных автомобилей с карточками.

Страница "Купить авто":
Детальная информация о выбранном автомобиле: название, мощность, пробег, цена, описание.
Галерея фотографий с возможностью увеличения.
Кнопка тест-драйва (концепт).
Горизонтальный скролл с похожими автомобилями.
Калькулятор автокредита для расчёта выплат.


Страница "Каталог":
Полный список автомобилей всего сайта

Страница "Конакты":
Форма обратной связи (ФИО, почта, телефон).
Отзывы клиентов о сайте.
Карта с отметкой местоположения автосалона.

Страница "О нас":
Краткая информация о компании.
Видеоролик с обзором.

Особенности и функционал:
Сравнение автомобилей в модальном окне.
Добавление машин в избранное.
Автокредитный калькулятор для расчёта выплат.


Технологии:
Frontend: Vue.js, HTML, CSS, JavaScript.
Дизайн: разработан в Figma.
Особенности: минималистичный концепт, адаптация под мобильные устройства.
